# Gap: Component Attenuation, Multivariate Response, and Scenario Scaling

Context:

We are preparing an English technical report for project `AR-S2J2J.R`, which
evaluates the effects of nearby blasting on a TSF. The project builds
prediction surfaces over charge and distance for component peak particle
velocity and component peak particle acceleration, then scales recorded blast
time histories to match predicted component peak accelerations for TSF scenario
products. The research gap is not a generic overview of scaled-distance
attenuation. The gap is whether component-wise or multivariate modelling and
component-peak scaling have support in blast-vibration literature for
geotechnical/TSF input preparation, and how to state limitations accurately.

Questions:

1. How does blast-vibration literature treat component PPV/PPA responses:
   separately by component, jointly as correlated responses, or through vector
   or resultant quantities?
2. What methods or diagnostics are used for multivariate or constrained
   response prediction when components are correlated or linked by a vector
   quantity?
3. Is there literature precedent for scaling recorded blast vibration time
   histories to match predicted component peak accelerations or velocities?
4. How should such scenario scaling be described so it is not confused with
   spectral matching, target-spectrum adjustment, or synthetic blast waveform
   simulation?
5. What limitations should be stated when scenario waveforms are scaled by peak
   component response rather than generated from a physics-based blast source
   model?
