## CONTEXT

This work supports an English technical report for project `AR-S2J2J.R`, which evaluates nearby blasting effects on a tailings storage facility (TSF). The engineering concern is saturated fine tailings and possible dynamic pore-pressure accumulation, cyclic mobility, or liquefaction-type response under transient blast-induced vibration. The project already has measured blasting records and scenario records; the research gap is the physical and mathematical basis for relating those dynamic histories to saturated-tailings response.
