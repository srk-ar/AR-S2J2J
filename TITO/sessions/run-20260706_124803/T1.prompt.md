## CONTEXT

This prompt supports an English technical report for project `AR-S2J2J.R`, a blast-induced ground-vibration study for a South African mining/TSF setting. The research gap concerns which standards, guidance documents, and charge-window definitions are authoritative enough to support professional report wording without inventing a compliance criterion. It does not concern basic definitions of PPV, PPA, component peaks, or scaled distance.

Describe how those sources distinguish structural damage criteria, human perception or comfort criteria, geotechnical effects, and monitoring/reporting requirements. Write in flowing paragraphs.

### SLOT 3: Charge Per Delay and Charge Window Definitions

Assess whether a 9 ms charge window is supported by standards or literature, or whether it should be treated as a project/vendor-specific definition unless project documents say otherwise. Write in flowing paragraphs.

### SLOT 5: Dual-Blast or Multi-Design Events

Describe how dual-blast or multi-design events should be described when charge and distance must be paired by blast design. Write in flowing paragraphs.
