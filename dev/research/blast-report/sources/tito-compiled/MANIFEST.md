# TITO Compiled Research Manifest

## Purpose

This folder preserves the compiled TITO research outputs needed for the
blast-vibration/TSF methodology work. These files were copied out of the
original TITO workspace so it can be removed without losing the research
record.

These files are evidence staging material, not public report prose. Selected
TITO-discovered sources have been curated into `bib/references.bib` with stable
keys; the raw `Ref###` BibLaTeX entries in this folder remain working evidence
only.

## Promotion Rules

- Replace `Ref###` keys with stable descriptive keys before public use.
- Replace `WebSource` titles with full metadata before public use.
- Do not cite generated KB Markdown as external authority.
- Do not use ResearchGate, vendor pages, or Semantic Scholar pages as final
  public sources when the primary paper/report can be curated.
- Keep TITO prose in ledgers until paragraph-level approval.
