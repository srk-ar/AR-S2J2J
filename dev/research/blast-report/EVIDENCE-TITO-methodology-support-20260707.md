# EVIDENCE-TITO-methodology-support-20260707

## Purpose

Track where the compiled TITO research naturally supports the professional methodology report, where it conflicts with the project scope, and where no connection should be invented.

This file is not public report prose. It is a source-control map for paragraph ledgers and citation curation.

## Evidence Rule

TITO outputs can hydrate ledgers in three ways:

- natural support: the TITO claim directly supports a methodology statement or limitation already present in the project;
- qualification: the TITO claim supports a limitation, caveat, or distinction that prevents overclaiming;
- no promotion: the TITO claim is irrelevant, contradicted by project scope, too generic, or lacks a curable primary source.

No `Ref###`, `WebSource`, generated KB Markdown, ResearchGate page, vendor page, or Semantic Scholar page should be cited in public prose. Public citations require stable keys in `bib/references.bib`.
